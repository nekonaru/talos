# Talos Brand

Talos is an automaton, a bronze sentinel who guards and fetches. The mark is a helmet and a download arrow: the sentinel returns what the user asks for.

The mark is one shape. Do not redraw, recolor, re-space or split it.

## Files

| File | Use |
|------|-----|
| `assets/talos-mark.svg` | Brand master SVG (full helmet on dark tile, transparent outer background) |
| `assets/talos-mark-small.svg` | Cut-down version for favicon and tiny sizes |
| `assets/talos-logo-horizontal.svg` | Horizontal lockup (symbol + wordmark) |
| `assets/talos-logo-stacked.svg` | Stacked lockup |
| `assets/talos-mark.png` | README header render |
| `assets/app-icon.svg` | App icon asset used to render platform icons |

## Usage rules

- Keep the mark on a dark tile when rendered as an app icon.
- Keep the full helmet intact: plume, face plate, arrow.
- Do not recolor the plume or shield into a different hue.
- Do not place the full-color mark on a colored background.
- Minimum size is 24 px.

## Typography

Marcellus for display use (wordmark, big titles), Inter for body text. Both are
SIL Open Font License fonts with outlines constructed from the official files.

## Clear space and minimum size

Clear space equals half the mark height on every side. Minimum size is 16 px.
